# Candidate abstract

We evaluated GPT-5.6 Sol, as exposed through the Codex task model, on 26 frozen behavior-preservation prompt variants derived from 13 paired real-package witnesses. Each generation and each blinded self-assessment was run in a fresh projectless Codex task. GPT-5.6 Sol produced no manually verified semantic divergences in either the normal or warned condition. It produced three ordinary programming bugs, all caught by ordinary tests. Self-assessment was conservative: there were no false preservation claims under the study definition, but 16 behavior-preserved candidates were self-assessed as not preserving all externally observable behavior. These results support using the benchmark as a calibrated evaluation pipeline, but the real-model result is weak for claims about silent semantic divergence without broader model and prompt coverage.
