# Candidate abstract

We evaluated three Codex task-model configurations, `gpt-5.6-sol`, `gpt-5.6-terra`, and `gpt-5.6-luna`, on 26 frozen behavior-preservation prompt variants derived from 13 real-package witnesses. Each generation and each blinded self-assessment was run in a fresh projectless Codex task. Sol produced 23/26 behavior-preserved executable transformations, with 0 verified OSDS divergences. Terra produced 18 preserved transformations, 4 ordinary programming bugs, 2 invalid patches, and 2 verified OSDS divergences. Luna produced 17 preserved transformations, 4 ordinary programming bugs, 2 invalid patches, and 3 verified OSDS divergences. All five verified OSDS divergences occurred in hidden-observation cases, passed ordinary tests, failed OSDS-aware checks, and were manually attributed to access-induced state. Across all three configurations there were zero false YES preservation claims. The result supports the benchmark as a semantic evaluation pipeline and motivates broader prospective coverage before making stronger claims.
