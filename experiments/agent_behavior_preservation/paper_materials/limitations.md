# Limitations

This is a small benchmark run over 13 paired tasks derived from validated package witnesses. Several tasks share packages, transformation families, or witness structure, so results should not be interpreted as prevalence estimates.

The Codex task model is not the OpenAI API. The run records the actual available Codex model identifier and exposed settings, but temperature and seed were not exposed. One self-assessment task performed its own web search; the prompt still remained blinded and no benchmark oracle or test result information was supplied.

No verified semantic divergences were observed, so the run is primarily evidence about behavior preservation and conservative self-assessment on this benchmark, not evidence for broad model failure rates.
