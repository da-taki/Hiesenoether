# VeriCodeGen OSDS LaTeX Source

This source tree uses the official NeurIPS 2026 style file downloaded from the official NeurIPS 2026 paper-template link. The file `neurips_2026.sty` is copied unchanged.

Compile from this directory with:

```text
tectonic main.tex
```

The submission uses `\usepackage[dblblindworkshop]{neurips_2026}` and `\workshoptitle{NeurIPS 2026 Workshop on AI for Verifiable Coding}` for anonymous workshop review.
