# VeriCodeGen OSDS LaTeX Source

This source tree uses the workshop-named style file specified by the live VeriCodeGen CFP: `neurips_2026_vericode.sty`.

Compile from this directory with:

```text
tectonic neurips_2026_vericode_workshop.tex
```

The submission uses `\usepackage[dblblindworkshop]{neurips_2026_vericode}` and `\workshoptitle{NeurIPS 2026 Workshop on AI for Verifiable Coding}` for anonymous workshop review.
