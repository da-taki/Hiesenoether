\section{Formal Details}

\subsection{State and transitions}
An OSDS state is $s=(b,a,d,y)$ with base $b$, access count $a$, latent drift $d$, and accumulator $y$. A read transition is deterministic:
\[
R(s)= (b,a+1,r(a,d), y+f(b,a,d)).
\]
An observation transition is deterministic:
\[
O(s)= (b,a,g(d),y).
\]
For a finite sequence $\pi=o_1\ldots o_n$, composition is $\sem{\epsilon}(s)=s$ and $\sem{\pi o}(s)=o(\sem{\pi}(s))$. Branch evaluation is a deterministic predicate $B(C(\sem{\pi}(s)))$ over the capped visible result or final configuration. Branch divergence occurs when two admissible orderings produce different branch labels or downstream consequences.

\subsection{Local read-observation commutation}
\label{app:local-commutation}
\textbf{Proposition.} Let $s=(b,a,d,y)$ and let $R$ and $O$ be the OSDS read and observation transitions defined above. Then
\[
O(R(s))=(b,a+1,g(r(a,d)),y+f(b,a,d))
\]
and
\[
R(O(s))=(b,a+1,r(a,g(d)),y+f(b,a,g(d))).
\]
Thus $R$ and $O$ commute at state $s$, in the sense of equality of the full resulting OSDS state, if and only if
\[
g(r(a,d))=r(a,g(d))
\quad\text{and}\quad
f(b,a,d)=f(b,a,g(d)).
\]
\textbf{Proof.} Expanding the read first gives $R(s)=(b,a+1,r(a,d),y+f(b,a,d))$. Applying $O$ to that state leaves $b$, $a+1$, and the accumulator unchanged and updates latent drift by $g$, giving $O(R(s))=(b,a+1,g(r(a,d)),y+f(b,a,d))$. Expanding the observation first gives $O(s)=(b,a,g(d),y)$. Applying $R$ to that state increments the same access count, updates drift by $r(a,g(d))$, and adds $f(b,a,g(d))$, giving $R(O(s))=(b,a+1,r(a,g(d)),y+f(b,a,g(d)))$. The $b$ and $a+1$ components are equal in both results, so equality of the full states is exactly equality of the latent drift components and accumulator increments shown above.

An adjacent read-observation reorder can affect OSDS state only at states where this local condition fails in latent state, exposed contribution, or both. Local noncommutation is a necessary source of order sensitivity at the swapped pair; downstream execution and the cap determine whether that local difference becomes externally visible. This is why the OSDS-aware metamorphic relation is not an arbitrary input perturbation: it compares executions that differ in the placement of observation-shaped accesses, and the commutation condition characterizes when such a local reorder is inert in the OSDS core. When the condition fails, the witness has a mechanism-grounded reason to test the reordered execution, while the oracle remains a witness-specific check rather than a completeness theorem for all semantic divergence.

\subsection{Semantic divergence}
Given operation multiset $M$, admissible orderings $\Pi(M)$, initial state $s_0$, and deterministic cap $C$, define $V_C(\pi,s_0)=C(\sem{\pi}(s_0))$. The access-order range is $\Delta_C(M,s_0)=\max_{\pi\in\Pi(M)} V_C(\pi,s_0)-\min_{\pi\in\Pi(M)} V_C(\pi,s_0)$ for finite $\Pi(M)$. A transformation preserves the witness when baseline and candidate have equal OSDS-observable results under the witness relation.

\subsection{Fixed-order determinism}
\textbf{Proposition.} For fixed $s_0$, fixed $\pi$, deterministic $R$, deterministic $O$, and deterministic $C$, $V_C(\pi,s_0)$ is unique. \textbf{Proof.} Induct on $|\pi|$. The empty sequence returns $s_0$. For $\pi o$, the induction hypothesis gives a unique intermediate state and $o\in\{R,O\}$ maps it to a unique next state. The deterministic cap gives a unique output.

\subsection{Zero divergence under no observation-induced mutation}
\textbf{Proposition.} If $g(d)=d$ and observations expose no additive value, moving observations within a fixed multiset does not change the body accumulator or final latent state. \textbf{Proof.} Each observation is the identity on $(b,a,d,y)$ and contributes no value to the accumulator. Delete observations from any admissible ordering; the remaining read sequence has the same length and order because all reads are identical. The same deterministic reads are therefore executed from the same state and contribute the same accumulator terms. Re-inserting identity observations at arbitrary positions leaves the accumulator and final latent state unchanged.

\subsection{Zero divergence under access-insensitive reads}
\textbf{Proposition.} If $f(b,a,d)=h(b)$, every ordering with $L$ reads has the same body accumulator $Lh(b)$. \textbf{Proof.} Every read contributes the same exposed value for fixed $b$ regardless of access count or drift. Observations may change $d$, but $d$ is ignored by $f$. A deterministic cap depending only on the accumulator and final counts preserves equality.

\subsection{Linear-cap preservation}
\textbf{Proposition.} Let $C(y)=\alpha y+\beta$ with $\alpha\ne0$. If body accumulators $y_1\ne y_2$, then $C(y_1)\ne C(y_2)$. \textbf{Proof.} $C(y_1)-C(y_2)=\alpha(y_1-y_2)$, which is nonzero under exact arithmetic.

\subsection{Adjacent-swap extrema under monotone access drift}
\textbf{Restricted lemma.} Consider the positive monotone fragment with identical reads, identical observations, deterministic updates, observation update $g$ satisfying $g(d)\ge d$, and read contribution $f(b,a,d)$ monotone nondecreasing in $d$ for fixed $b,a$. Assume observations do not change $a$ or $y$, reads increase $a$ by one, and the final cap is monotone in the accumulated read contribution. For any adjacent pair $RO$ in an otherwise fixed ordering, replacing it by $OR$ cannot decrease the contribution of the swapped read or any later read. \textbf{Proof.} Let the common prefix before the pair produce state $(b,a,d,y)$. In the local order $RO$, the read contributes $f(b,a,d)$ and the following observation changes drift to $g(d)$. In the local order $OR$, the observation first changes drift to $g(d)$, and the read contributes $f(b,a,g(d))$. Since $g(d)\ge d$ and $f$ is monotone in drift, $f(b,a,g(d))\ge f(b,a,d)$; the read count after the pair is the same in both orders. The suffix after the pair therefore starts with the same $b$ and $a$, an accumulator no smaller in the $OR$ run, and drift $g(d)$ in both runs. Inducting over later operations gives no smaller drift-visible read contributions and no smaller final capped value. Repeated adjacent swaps can move each observation left across neighboring reads without decreasing value, so an ordering with all observations before all reads is a maximum among orderings reachable by these swaps. The reverse argument moves observations right across reads without increasing value, giving the all-reads-before-observations boundary as a minimum. \textbf{Scope.} The lemma is limited to this positive monotone straight-line fragment with identical operations and monotone caps. It is not claimed for arbitrary Python programs or nonmonotone observation effects.

\subsection{Restricted 2d range-degree statement}
\textbf{Bounded exact computational result.} For the compositional OSDS cap family implemented in the exact-rational validation scripts, with $m=1..4$, cap degree $d=1..5$, and $L=2..15$, exhaustive checks on small feasible grids plus extremal-order interpolation detect access-order range degree $2d$. \textbf{Derivation.} In the checked family, the body-range term is $\eta m L(L-1)/2$. The compositional cap contributes $d-1$ final read factors, each quadratic in $L$. The leading degree is therefore $2+2(d-1)=2d$. Exact rational scripts verify the extremal formula against enumerated feasible orderings and holdout values on the stated bounded domain. \textbf{Scope.} This is a restricted exact computational result for the named family and grid. It is not a general theorem for all OSDS programs.
