\section{Introduction}

Program transformations often treat logging, representation, inspection, caching, and repeated access as behavior-preserving. That treatment is valid when the accessed operation is observational in the semantic sense. It can fail when the operation updates latent state that a later read exposes. We call this pattern access-induced semantic divergence.

The phenomenon is related to observer effects and probe effects, but the paper studies a specific sequential mechanism: an observation-shaped access mutates latent access state, and a later program result changes. This matters for generated code because requested edits are often local and plausible. A model may add instrumentation, memoize a representation, or simplify repeated access while preserving ordinary tests that do not vary observation order.

We study this mechanism through three layers. The first layer is an observation-sensitive deterministic-system (OSDS) model. It separates exposed read values from latent access state and supports formal statements about determinism, zero-divergence conditions, and preservation of body-level divergence under a linear cap. The second layer is a real-code oracle over unmodified Python packages. It confirms executable package witnesses and caller-level effects. The third layer is a frozen generated-transformation study built from those witnesses.

The empirical claim is bounded. We do not estimate ecosystem prevalence, and the three tested Codex task-model configurations are not independent model providers. The main result is mechanism-grounded: in the primary benchmark, five generated outputs silently violated OSDS preservation under ordinary checks, and all five failures disappeared when the identified access-induced mechanism was neutralized while the generated code stayed fixed.

\textbf{Contributions.} We make four contributions. First, we give an OSDS formal model for access-state-carrying sequential systems. Second, we report 20 confirmed real-package divergences across 12 packages, including 9 caller-level branch effects. Third, we evaluate frozen generated transformations and identify five silent OSDS failures across Terra and Luna configurations, with zero false YES self-assessments in the primary study. Fourth, we correct the prospective expansion accounting by separating task compliance, ordinary correctness, and OSDS preservation: 23/42 prospective outputs were task-compliant transformations, 19/42 were unchanged, and 0/42 produced verified OSDS divergence.
