\begin{abstract}
Access-induced semantic divergence occurs when an operation that appears observational updates latent access state and changes a later externally visible result. We formalize this pattern as observation-sensitive deterministic systems (\osds), prove bounded structural properties for a straight-line core, and evaluate it on real Python packages and generated program transformations. The real-code study confirms 20 divergences across 12 unmodified packages, with 9 caller-level branch effects and 19/19 mechanism controls eliminating divergence. A frozen primary coding-agent benchmark contains 13 base tasks and 26 normal/warned variants. Across three Codex task-model configurations, five model-task outputs were verified OSDS failures, all concentrated in two underlying package witnesses. The benchmark ordinary checks missed all five; OSDS-aware evaluation detected all five; mechanism-neutralizing controls reproduced and removed 5/5. A prospectively frozen expansion added 7 base tasks and 14 variants. Auditing the 42 prospective outputs separately, 23/42 were task-compliant transformations, 19/42 returned unchanged code, and 0 produced verified OSDS divergence. The results support a bounded conclusion: generated transformations can silently violate access-sensitive semantics on validated witnesses, and OSDS-aware replay plus causal controls provide a verifiable method for detecting and attributing this failure mode.
\end{abstract}
